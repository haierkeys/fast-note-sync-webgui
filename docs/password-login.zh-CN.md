# 无密码 / 仅 SSO 登录

服务端公开接口 `GET /api/webgui/config` 可返回
`data.passwordLoginIsEnable: false`。共享登录组件收到该值时，移除本地用户名/密码
登录及注册表单（即使注册开关单独开启），保留全部 OIDC 身份提供商按钮。
主 WebGUI 和 OAuth 授权页的登录流程均使用此组件。

旧服务端缺少该字段或能力获取失败时，保留原有密码表单。服务端必须强制执行策略；
隐藏表单不是安全边界。本修改不启用任何身份提供商。若关闭密码且没有可用 OIDC，
界面显示联系管理员的提示，不提供密码回退入口。

配套服务端配置为 `user.password-login-is-enable: false`，修改后重启。
关闭前请先验证 OIDC 和管理员权限，避免锁定。现有会话、API Token 和插件令牌
签发流程不受影响。

后端内嵌编译后的 WebGUI 资源，维护者需要按正常资源发布流程集成本前端修改；
本 PR 不替换后端的已编译资源包。
